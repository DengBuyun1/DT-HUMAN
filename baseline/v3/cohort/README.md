# 多对象独立回测

多对象入口逐工作簿运行 V3 日级、小时级和滚动评估，另提供最长连续分钟心率半分和确认运动场次的补充实验。各对象独立训练、标准化、测试和比较基线。

在 `baseline/` 目录安装根 README 所列依赖，将授权输入目录和本地结果目录传给入口。工作簿沿用 `健康数据2.xlsx` 至 `健康数据6.xlsx` 的命名。

```powershell
py -3.10 -X utf8 -m v3.cohort.batch_subjects --source "<授权工作簿目录>" --output "<本地结果目录>" --subjects 2 3 4 5 6
```

五份工作簿均无确认游泳场次，只有一份同时包含确认类型的训练和测试运动。分钟心率 RMSE 中，Ridge 在一份工作簿误差更小，上一值基线在四份误差更小。各工作簿的时间覆盖和测试段不同。
