## 3. 新方案内部的执行顺序

`P0 历史基准留存 → P1 数据口径修正 → P2 协议与划分冻结 → P3 固定半段复测 → P4 有限模型优化 → P5 滚动与敏感性检查 → P6 决策、图册和交付`

- P0—P2 未完成，不开始解释 V3 模型效果。
- P3 先回答“修正目标后，简单基线表现如何”。
- P4 只实施预先列出的低复杂度候选；模型不胜出也是有效结果。
- P5 与固定半段主实验分别报告，不能合并成一个“最佳效果”。
- P6 根据证据将模块标为预测候选、基线参考、仅观测展示或证据不足。

## 4. 后续版本规则

- 修正文案、路径、非实质性说明：V3.0.1，更新变更记录。
- 改变目标、样本排除、主划分、模型集合、主要指标或采用门槛：V3.1，新增方案文件和实验批次，不覆盖 V3.0。
- 新增数据、全新任务或基础模型微调：另列后续阶段；不得把现有数据复测写成独立新数据验证。
- 每个后续运行目录保存对应方案副本及 SHA-256，不能只指向一个会继续修改的“最新方案”。
