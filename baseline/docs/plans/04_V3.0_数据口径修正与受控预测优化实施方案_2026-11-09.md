4. 在新运行清单登记父运行 `连续半段-20261109-192322-716804` 和参考 V2 运行 `v2-20261109-170819-386454`。

### 4.2 统一基础清理

- 依据“指标类型＋测量时间”分组；相同值重复只保留一份，多值冲突整组标记并从模型输入、标签中排除。
- 实时心率与静息心率分别处理；两个不同指标的同时间记录不构成冲突。
- 时间统一解释为北京时间。没有时区的源时间采用此约定，并在清单记录。
- 缺失、解析失败、非有限值、单位不明均保留原因。明显不可能的非正心率不进入计算；不根据测试效果新增数值裁剪阈值。
- 不用未来值插补输入，不填造未测的血氧、睡眠、体成分，不用线性插值制造连续标签。
- 维护 `raw_row_id → cleaned_record_id → aggregate_id → prediction_id` 的追溯关系；原始值留存于本地。

### 4.3 日心率新定义：观测小时等权心率摘要

按下列顺序聚合：

1. 从统一清理后的实时心率构造固定 5 分钟网格，区间采用左闭右开。
2. 每个有观测的格子取中位数；没有观测保留缺失。格子结束前不能使用该格子的最终统计量。
3. 一小时至少有 **3 个不同的有效 5 分钟格子**才合格；小时摘要为有效格子中位数。
4. 一天至少有 **8 个合格小时**，且分布于 **至少 3 个不同的 6 小时时段**，才计算日摘要。四个时段为 00—06、06—12、12—18、18—24。
5. 日摘要为合格小时摘要的中位数，各小时等权。
6. 日摘要在当日结束后才可作为次日预测的输入；不视为当天零点已知。

字段建议为 `hr_observed_hour_balanced_v3`，界面名称为“观测小时等权心率摘要”。该统计量仍只代表有记录的时段；8 个合格小时不等于完整全天监测，不能把它写成全天真实平均心率。

同时保存：原始读数数、去重数、冲突数、有效 5 分钟格数、合格小时数、24 小时覆盖掩码、覆盖时段数、游泳内记录比例。游泳内外分组用于描述性诊断，不把当日实际游泳情况作为当日事前预测的已知特征。

**覆盖敏感性：**仅把日合格条件从 8 小时提高为 12 小时，仍要求覆盖至少 3 个时段；其他规则完全一致。两个阈值由本轮设计预先列出，不能按测试误差挑选。此前只读覆盖可行性检查显示，8 小时规则可保留 31 天，12 小时规则可保留 25 天；这些是设计可行性信息，正式实现必须重新核验，不是新模型效果。

### 4.4 其他指标口径

| 指标 | V3 规则 | 特别限制 |
|---|---|---|
| 压力、血氧日摘要 | 同样先固定 5 分钟格、合格小时再等权聚合；主覆盖规则为 8 小时且 3 个时段 | 稀疏指标可能大量不合格；不为保留样本私自降低门槛。原读数日中位数可作为不同目标的描述性附表 |

## 5. P2：冻结数据划分、可用信息与实验协议

### 5.1 协议 ID 和先后关系

| 协议 ID | 角色 | 划分与更新规则 |
|---|---|---|
| `V3-F50` | **主协议：固定前后半段** | 完整日历 D01—D31，D01—D15 训练，D16—D31 测试；模型参数、标准化和超参在测试前冻结；游泳整场按同一日期边界分配 |
| `V3-C50` | **连续段专项，保留用户要求** | 对日／小时每个指标的新定义，选最长合格连续段，前 `floor(N/2)` 点训练，其余测试；并列最长取最早段；逐项列出日期，不混称同一测试期 |
| `V3-ROLL` | 补充：逐日适应性更新 | 与 F50 相同首个测试日；每天只用此前日期重训，同一天所有场次共用模型；与 F50 分开评分 |
| `V3-CAL` | 补充：固定点预测＋在线误差参考 | 点模型固定，只用已到期历史预测残差更新经验误差带；单独记录更新的信息 |
| `V3-SENS` | 敏感性检查 | 预定的覆盖阈值、评分子集、日期删除、实际活动时间等；不据此改写主结果 |

对原本完整的 31 天指标，F50 与 C50 在新目标仍完整时相同，只运行一次并登记两个用途，不能当成两次独立验证。

新覆盖规则造成缺失时：F50 保持原日期边界，合格目标才能评分；C50 另按真实连续段半分。两套结果都报告，不能选择较好的一套作为唯一结论。C50 按整份记录的完整性事后选段，只代表资料较齐的时段。

游泳不会把每个场次切成前半场训练、后半场测试。主问题仍是以前的场次训练、之后完整场次测试；后半场测试不属于本方案的默认任务。

### 5.2 输入观测与参数更新分开管理

每条预测保存 `information_mode`：

- `online_one_step`：先发出预测，等目标结束并到达后，真实值可作为下一步输入。F50 下参数仍不更新。
- `open_loop`：仅使用训练末端状态和之后模型自己的预测，不读取后半段真实目标、真实活动统计或未来场次信息。
- `conditional_duration`：给定一次运动的时长估算设备热量。输入是计划值或实际值必须分别注明。

开环模型须在规则完整的 C50 连续段上给出主诊断；若 F50 存在标签缺失，可继续按日历步长递归，但缺失日不评分。不得把相隔多日的两条有效记录拼接成相邻一天。

### 5.3 数据可用时刻

- 30 秒心率窗口仅在窗口结束后可用；目标提前量相对预测发出时刻计算。
- 日汇总约定在该日结束后可用，即次日 00:00；这是回顾模拟的约定。
- 睡眠在事件结束后可用；实际整场时长和实际活动时间在运动结束后才完整可知。
- Excel 没有可靠的上传／同步时间，不能把以上约定写成已验证的线上实时延迟。清单必须记录 `availability_assumption`。
- 训练样本需满足标签可用时间早于或等于训练截止；同一日期所有游泳场次一起划分，跨界场次按结束时间检查后整场处理，不拆分以增加样本。

### 5.4 最小数据条件与缺失处理

- 单变量 Ridge：至少 8 个有效训练点且至少 7 个真实相邻训练对；训练输入不全为常数。
- 模型数值结果可在至少 4 个有效测试点时输出；只有少数小时／日期时仍标证据不足。
- 游泳 Ridge：训练至少 3 个日期、每日期有有效训练窗口；实际日期数、窗口数全部登记。低于条件只给保持值参考。
- 基线可以在有历史记录时给出参考，但不足的数据不能满足“模型采用”门槛。
- 缺失输入时，主要模型输出“输入不足”；若启用回退基线，记录 `fallback_used`。单独报告模型覆盖和含回退的系统覆盖，不把回退效果算成候选自身能力。
- “上一时点”基线只使用真正相邻时点；“最近有效值”如跨缺失使用，另存 `age_since_observation`，不得混称连续一步。

## 6. P3：日级／小时级固定基线复测

### 6.1 模型集合

第一轮不增加复杂日级预测器，仅使用：

| ID | 方法 | 在线一步 | 开环 |
|---|---|---|---|
| D-B0 | 训练段中位数常量 | 是 | 是 |
| D-B1 | 训练段均值常量 | 是 | 是 |
| D-B2 | 相邻上一时点实测 | 是 | 否 |
| D-B3 | 冻结训练末端实测 | 是 | 是 |
| D-R0 | 单滞后标准化 Ridge，alpha=1 | 是，输入相邻已到达实测 | 是，输入上一步预测 |

所有统计量和标准化参数只从训练段获得。训练相邻对必须时间差恰好为一天／一小时。主实验不按测试误差搜索 alpha、滞后数量或指标组合。

### 6.2 必须回答的问题

1. 新目标下，Ridge 是否优于训练均值和训练中位数？
2. 在线任务中，Ridge 是否优于相邻上一时点实测？
3. 开环是否只是快速收敛为常量？
4. 若误差降低，是否同时保留了对真实变化的解释能力？
5. 结论是否依赖某个日期或某个覆盖阈值？

结果至少包含 MAE、RMSE、偏差、P90、最大误差、R²、预测标准差／观测标准差、实际和预测轨迹。常量导致相关性不可定义时写 NA；不把 NA 置零。R² 使用测试均值作描述性参照，不把测试均值当作可以提前获得的预测器。

原始读数日中位数与新日摘要是两个不同目标。主比较必须在相同新目标和相同样本上完成；旧目标只保留历史复现和聚合诊断。

### 6.3 稀疏指标的安排

- 静息心率保留单变量复测；本轮不再大规模搜索活动／睡眠组合。
- 主睡眠、小睡若不足 8 个训练点，仅报告基线和观测，不宣称完成学习模型训练。
- 体重与体成分不开展新的预测训练，输出数据覆盖和已有测量图。
- 小时多指标联合连续段很短，本轮不训练高维联合模型。
- 血氧若常量基线更好，则采用个人参考值展示；数值稳定不等于模型学会了低氧变化。

## 7. P4-A：游泳心率有限优化

### 7.1 目标与输入保持明确

- 目标：未来 30 秒或 120 秒处的 **30 秒窗口设备心率中位数**，两个提前量独立训练、评价。
- 精确定义：发出时刻为 `t`、提前量为 `h`，目标窗口是 `[t+h−30秒, t+h)`，其统计量在 `t+h` 才可用。30 秒预测对应紧接当前输入窗口的下一个窗口。
- 每个 30 秒窗口至少 2 个不同时间戳、非冲突的实测才有效，不填充缺测窗口。
- 输入沿用此前 3 个有效且相邻的窗口、均值、变化量和已运动时长；不加入整场最终平均心率、最终时长、未来运动强度。
- 主要输入资格只依赖过去：最近三个窗口有效即可尝试发出。未来目标是否存在，只决定之后能否评分。
- 训练主要样本要求输入有效且目标有效；中间未来窗缺测不必排除。旧版要求输入至目标全程完整的训练口径另做复现。比较原 Ridge 与新候选时使用同一训练集合，防止将训练样本变化归因于模型改进。

### 7.2 主模型矩阵

| ID | 模型 | 地位与唯一变化 |
|---|---|---|
| HR-B0 | 保持当前心率 | 两个提前量都必须报告的强基线 |
| HR-B1 | 训练心率均值常量 | 按训练场次等权，检查是否仅靠回归常态 |
| HR-R0 | 原版 Ridge，alpha=15 | 新清理／新评分口径下重新拟合的参照 |
| HR-R1 | **增量 Ridge，alpha=15** | 唯一新增主候选：把目标改为未来心率减当前心率，预测后加回当前值 |

HR-R1 的形式为：

\[
\Delta y_{t,h}=y_{t+h}-y_t,\qquad
\hat y_{t+h}=y_t+\widehat{\Delta y}_{t,h}.
\]

HR-R0 与 HR-R1 使用相同训练窗、输入特征、标准化、场次权重、正则强度。目标变换改变了正则化倾向，这是本次唯一需要隔离检验的模型改动。预期检验的问题是高值低估／低值高估能否缓解；不预先保证改善。

加权 Ridge 与 Kalman 的既有结果保留；本轮默认不继续搜索其参数。Chronos-2 和 LoRA 不进入本轮默认执行队列。

### 7.3 调参预算

主 F50 实验全部冻结 alpha=15。只有 4 个训练日期，不做大规模搜索。

一个可选补充实验允许 HR-R0、HR-R1 同时搜索 `{5,15,50}`，但每个内部训练折仍须至少 3 个日期，且至少有 2 个合法可评分验证日期。因此，当前 F50 只有 4 个训练日期，只能形成“前 3 日期→第 4 日期”一个合法折，**不启动搜索，保持 alpha=15**。在 ROLL 的某个后续训练前缀达到至少 5 日期时，若事先启用了该补充，可取训练内部最后 2 个日期分别作前向验证，各自只用更早日期拟合；仅按这两个训练内部验证日期的均衡 MAE 选择。任一折不可评分则回退 15。并列绝对差不超过 `1e-8` 时优先 15，其次 5、50。每模型每提前量每次选择最多 6 次内部拟合；结果另列，不替代固定 alpha 主实验。该补充默认关闭，启用状态须在读取 V3 新测试结果前记录配置，不能看到后半段效果后临时开启。

### 7.4 评分集合和覆盖

主集合为所有“输入有效、已经发出、目标实际可见”的预测。严格连续集合只作敏感性结果。

分别记录：可尝试时点、输入足够时点、实际发出、目标可见、严格全程连续、目标缺失、记录结束后才到期、回退和拒答。所有模型按同一资格比较；同时报告各自全量覆盖，不能靠共同交集掩盖候选不输出的部分。

回放按已经到达的输入窗口产生预测，不得因为离线已知文件结束时间，就提前取消最后 30／120 秒内本应发出的预测。结束信息到达后停止发出；此前已发出而在记录范围外到期的预测单列。记录范围内、范围外的发出数分开统计，覆盖率分子与分母保持相同时间范围。

实现时建立新的逐事件发出循环，不直接沿用旧 `swim.cases` 中依赖 `len(heart)-step` 的末尾截断。原函数可用于训练样本整理或旧实验复现，不能替代 V3 的实时资格判定。

按每场先平均、同日期场次等权、日期再等权计算主 MAE。另报逐窗 MAE、逐场结果、每组样本数、P90、最大绝对误差、偏差、±10 次/分比例。±10 只是本项目描述性工程容差。

## 8. P4-B：游泳热量估算与外推控制

### 8.1 任务定义

主任务为“给定一次游泳的实际总时长，估算该设备记录的整场热量”。采用原表总时长与运动热量字段，不把日活动热量混入同一标签。

计划时长页面属于条件情景：计划值可以提前输入，但现有回测只验证实际时长与实际设备热量的关系，没有验证是否完成计划或干预因果效果。

### 8.2 模型矩阵

| ID | 方法 | 用途 |
|---|---|---|
| E-B0 | 训练整场热量中位数 | 检验是否利用时长 |
| E-R0 | `median(E/t) × t` | 默认固定消耗率模型 |
| E-R1 | 旧非负斜率、带截距直线 | 保留失败诊断；不作为全时长默认模型 |
| E-R2 | 非负、过原点最小二乘率 | 本轮唯一新增热量候选，无额外搜索 |

E-R2 的系数为：

\[
k=\max\left(0,\frac{\sum_i t_iE_i}{\sum_i t_i^2}\right),\qquad \hat E(t)=kt.
\]

E-R0、E-R2 都满足 `E(0)=0`。此处是条件估算的结构约束，不据此宣称设备热量等于真实运动净能耗。

### 8.3 支持范围与采用规则

- 训练支持范围仅由当次训练场次确定；主 F50 当前为 38—60 分钟。
- 对全部 10 场测试输出研究评分，并同时列范围内、范围外、短场案例。已知短场必须保留，不能事后删为异常值。
- 页面正式候选输出限定支持范围；范围外可另显示固定消耗率参考，标“超出训练支持范围”，不计为经过验证的正式输出。
- 报告正式支持覆盖率与参考覆盖率。当前只有 4/10 测试场在旧训练时长范围内，不能仅展示这 4 场的漂亮误差。
- 同时报日期等权、逐场等权 MAE、P90、最大误差、偏差。日期均衡改善但逐场或尾部恶化时不自动采用。
- 实际活动时间单独作为 E-SENS 事后条件分析；不能与实际总时长混在一列或用于证明事前可预测。

## 9. P5：滚动稳定性、误差参考与敏感性

### 9.1 滚动验证

从与 F50 相同的首个测试日期开始，每天在该日第一条预测前，用前一天及更早已经可用的数据拟合。当天所有场次使用同一版本，次日才更新。无随机打乱，无同日期场次交叉进入训练和测试。

比较 F50 和 ROLL 时，区分“参数更新带来的适应”与“模型结构改动”。测试日期、目标与评分资格一致；若某模型输入缺失，报告覆盖差异并另列共同集合。滚动结果不能充当固定半段结果的替代品。

### 9.2 经验误差带

固定实验的 4 个训练日期只能产生很少的前向校准日期，本轮不输出带有理论覆盖保证的区间。

独立的 V3-CAL 次实验采用：

1. 点模型和参数保持 F50 版本。
2. 先评分到期预测，再接收当前观测，再更新历史残差，最后发出新预测。
3. 仅使用先前已经结束且已评分的日期；当前日期残差最早在次日加入参考。
4. 至少有 **5 个既往可评分日期**才显示经验误差带；不足时显示“误差参考不足”。
5. 以日期等权、同日场次等权、场内窗口等权构成绝对误差经验分布，取加权 90% 分位数 `q90`，显示预测值上下 `q90`。
6. 分别校准 30／120 秒，报告实际覆盖、平均宽度、启用日期数、启用窗口比例。

称为“历史经验误差参考”，不称保覆盖置信区间。该方法读取了较早测试日期的已到期残差，因此必须独立标记为在线误差校准，不与完全固定评估混称。

### 9.3 预先列出的敏感性集合

| ID | 唯一变化 | 如何解释 |
|---|---|---|
| S01 | 日覆盖由 8 小时改为 12 小时，仍覆盖 3 个时段 | 评价覆盖要求对目标和结论的影响；不能选优后替换主规则 |
| S02 | 游泳全目标可见集合改为严格全程连续集合 | 评价缺测筛选影响，完整性只作事后条件 |
| S03 | 每次从汇总中删除 1 个测试日期，预测不重训 | 评价结论是否被单日主导；不是增加独立样本 |
| S04 | 热量输入实际总时长改为实际活动时间 | 事后条件估算差异 |
| S05 | 心率按真实目标区间与场次切片 | 事后误差诊断，不用于预测时选模型或筛样本 |
| S06（默认关闭） | 固定 alpha 改为训练内两个前向折选择 | 仅评估小范围调参敏感性 |

S05 心率区间使用预定的 `<120`、`[120,140)`、`[140,160)`、`≥160` 次/分，仅为便于复查的数值分层，不代表临床分区；每格披露窗口／场次／日期数。过少的分组仅列原始误差，不给稳定性结论。

## 10. 实验矩阵与可证伪问题

主性能问题为：**在同一人的后续游泳日期，HR-R1 相对同口径 HR-R0，能否改善 120 秒预测而不损失覆盖或加重误差尾部？**

统计单位是同一人的日期及其内场次／窗口，没有随机化单位。日期也可能时序相关；日期均衡用于防止长场次支配，不代表日期自动独立。

| 实验 ID | 对应问题／假设 | 唯一变化与对照 | 主要指标 | 失败／无结论条件与行动 |
|---|---|---|---|---|
| X00 | 旧结果能够复现 | 固定旧数据、旧代码与旧协议 | 指标误差、哈希、计数 | 超容差且无法解释：停止性能分析，修实现 |
| X01 | 日心率受聚合密度影响 | 原读数中位数 vs 小时等权摘要，同原始日记录 | 目标差值、覆盖、采样占比 | 差异不大也保留结果；不据此声称模型提升 |
| X02 | 修正后的日级 Ridge 有额外价值 | D-R0 vs D-B0/B1/B2/B3，同目标同样本 | MAE、P90、R²、动态幅度 | 未超过强基线或趋于常量：基线／常态参考 |
| X03（主要） | 增量建模改善 120 秒预测 | HR-R1 vs HR-R0，全部其他条件相同 | 日期均衡 MAE；覆盖、P90 为约束 | 不过第 11 节门槛：保留原 Ridge；数据不足：无结论 |
| X04 | 30 秒学习模型有额外价值 | HR-R0/R1 vs HR-B0 | 日期均衡 MAE、P90、覆盖 | 未过门槛：保持值参考 |
| X05 | 新热量率模型改善条件估算 | E-R2 vs E-R0，同训练与同支持范围 | 日期 MAE、逐场 MAE、P90、支持覆盖 | 指标矛盾或样本少：保留 E-R0 |
| X06 | 滚动更新的收益具有日期稳定性 | ROLL vs F50，结构相同 | 逐日差值、删日敏感性、覆盖 | 方向翻转：只报告日期敏感，不默认升级 |

不以“完成优化任务”为由强制新模型胜出。所有失败候选与无结论结果一起交付。

## 11. 验收规则、失败分支与采用决定

### 11.1 第一层：实现正确性，必须通过

- 目标、单位、统计量和标签来源有明确数据字典。
- 训练数据和标准化只在训练截止前拟合；预测输入截止不晚于发出时刻。
- 测试标签变化不会影响此前已经发出的预测；开环全部后半段预测不读取任何后半段标签。
- 日期／场次／窗口计数正确；缺失不置零，不拼接时间间隔。
- 主结果可从保存配置重算；数据、代码、配置和产物哈希可核对。
- 任何一项失败：暂停解释模型效果，先修正和重新生成新运行。

### 11.2 第二层：研究演示采用门槛

以下为依据既有诊断制定的**工程筛选规则**，不等价于统计显著、临床有效或跨人泛化。至少有 **5 个可评分测试日期**才评价采用；不足可报告数值，决定为“证据不足”。小时段的多个小时不能凑成多个日期。

| 任务 | 指定比较对象 | 候选进入研究演示的条件 |
|---|---|---|
| 游泳 120 秒新候选 | 同口径原 Ridge与保持当前值，两者都检查 | 对两个参照分别满足：日期 MAE 至少降低 5% 且绝对降低 0.5 次/分、严格多数日期改善、P90 不增加、发出覆盖不降低、删任一日期后改善方向不反转。原 Ridge 自身保留默认地位时，也须对保持值通过同一组门槛；新候选不能只超过一个较差的 Ridge 就获采用 |
| 游泳 30 秒候选 | 保持当前心率 | 同上，绝对改善阈值为 0.5 次/分；未达到则采用保持值参考 |
| 日级／小时学习模型 | 均值、中位数、冻结末值；在线再加相邻上一值 | 共同集合上相对这些可用基线均达到至少 5% MAE 改善，P90 不增加、覆盖不减少，多数日期改善且删日方向稳定；动态推演称谓另需正 R² 和可解释的波动幅度检查 |
| 热量 E-R2 | 固定消耗率 E-R0 | 在同一训练支持范围内的共同测试场次计算：日期 MAE 至少改善 5%，逐场 MAE 不劣、P90 不劣；另要求支持覆盖不降、零时长为零。支持范围内不足 5 测试日期时，不批准替代默认模型。全场和范围外误差另报，不能混入该采用集合 |

日级候选要求对列出的固定基线分别展示比较，不能事后挑最弱基线。开环不与读取测试实测的上一值基线混比；在线和开环各用合法的信息条件。

“正 R²”只是一项动态能力检查，不能单独证明孪生有效；预测标准差／观测标准差很小需明确标为收缩。不得通过添加随机噪声制造看似相似的波动。

按目前 F50 数据，热量支持范围内只有 4 个测试日期，因此即便 E-R2 数值较好，本轮该协议下的替代决定也应为“证据不足”；保留固定消耗率作条件参考。ROLL 的采用集合和决定另算，不合并协议来凑足日期。

P90 等不恶化允许 `1e-8` 数值容差。未预设临床可接受误差，因此不能使用“健康应用合格率”等措辞。

### 11.3 决策状态

每个指标／提前量单独输出以下一种状态和证据：

- `research_candidate`：通过本轮工程门槛，可进入个人研究演示；仍属于回顾性证据。
- `baseline_reference`：学习模型无实质增益，采用简单参考值／保持值。
- `observed_only`：只展示实测和覆盖，不给学习预测。
- `insufficient_evidence`：有效日期、输入或验证支持不足。
- `implementation_failed`：数据处理、时间顺序或复现失败，不能解释性能。

若平均误差改善但覆盖／尾部恶化，状态不得直接写通过。先报告取舍，本轮默认保留旧的较稳妥方法。失败后不追加未预定的大规模搜索；实质改动进入 V3.1。

### 11.4 统计表述

主报告以效应差、每日期配对误差和删日敏感性为主，不对重叠窗口做独立样本 t 检验，不把多个随机种子或重复划分当作新增人员。

本轮默认不进行正式显著性宣称，也不提供伪精确的样本量功效结论。如后续增加推断分析，须另写 V3.1 修订，规定比较族、日期相关处理、区间构造和多重比较规则。小样本区间需要明确假设，不能用简单窗口重采样包装稳定证据。

## 13. 关键验证、可复现记录与产物

### 13.1 必须执行的行为验证

时间因果扰动检查固定已经保存的 `split_manifest`、原始候选发出时间网格和模型配置。删除目标后重新选择 C50 最长段属于另一个覆盖／划分敏感性实验，不与训练隔离检查混用。未来目标缺失在其原本可用之前不应改变已发出预测；其后在线模型可以因少了一个输入而改变输出或拒答，开环仍须不受影响。

| 检查 | 操作 | 应满足的结果 |
|---|---|---|
| 聚合权重 | 在同一 5 分钟格复制等值记录 | 不改变格子及上层统计量；重复不增加覆盖 |
| 冲突一致性 | 同指标同时间加入不同值 | 该时刻统一标冲突，不只在部分任务排除 |
| 小睡总量 | 输入两次非重叠的合成小睡，分别为 20 和 30 分钟 | 总量 50，中位数 25 |
| 小时日期 | 测试点跨两日共 25 小时 | `n_slots=25`，`n_dates=2` |
| 训练隔离 | 改变后半段目标后重新拟合 | 训练参数、标准化、初始预测不变 |
| 开环隔离 | 替换全部测试期目标和活动统计 | 全部开环预测不变 |
| 在线因果顺序 | 只改变未来目标 | 目标可用前已发出的预测不变，之后允许变化 |
| 未来缺失 | 改变未来目标是否缺测 | 该目标可用前的发出资格与已发出预测不变，评分资格相应变化；之后的在线输入可受影响 |
| 连续性 | 在中间删除一天／一小时 | 不产生跨缺口的相邻训练对 |
| 同日场次 | 同一天有多场游泳 | 使用同一训练截止和模型版本 |
| 热量结构 | 输入 0 分钟和范围外短时长 | 正式率候选输出 0；范围外带状态，研究评分仍保留 |
| 重复运行 | 同配置复跑轻量模型 | 逐条预测在声明容差内一致，分组计数和采用状态相同 |

## 15. 执行顺序、停止规则与完成定义

### 15.1 必须按顺序执行的工作包

| 顺序 | 工作包 | 输入前提 | 完成标志 | 不满足时 |
|---|---|---|---|---|
| **P0** | 历史基准留存和复现 | 旧数据／源码／结果可读 | 旧运行登记、指标复算通过 | 修复版本和数据对应关系 |
| **P1** | 统一清理、聚合与元数据修正 | P0 通过 | 数据字典、覆盖、典型案例与行为验证通过 | 暂停训练 |
| **P2** | 冻结目标、划分、配置和失败分支 | P1 完成 | 方案副本、配置哈希、样本划分清单 | 明确缺项后再运行 |
| **P3** | 固定半段基线与旧模型复测 | P2 冻结 | F50/C50 在线和开环结果齐全 | 无样本任务如实标记，不补造 |
| **P4** | 增量 Ridge 与过原点热量候选 | P3 可复现 | 同口径模型比较、单项改动解释 | 不胜出则保留基线／原模型 |
| **P5** | 滚动与预定敏感性、经验误差参考 | P4 输出完整 | 所有预定补充结果或跳过原因 | 不因不利结果反复搜索 |
| **P6** | 图册、模块决定与交付 | P0—P5 状态明确 | 报告、图册、复跑说明和验证记录 | 明确未完成项目，不能假报全部完成 |

本表表示逻辑依赖，不承诺未经测量的耗时。P1 内的清理与字段审计可并行；P3/P4 不应越过 P2 先读取新测试效果再修改配置。

### 15.2 本轮预算与停止条件

- 默认主心率方法 4 个、2 个提前量；默认热量方法 4 个；日级采用 5 个固定方法，不增加神经网络搜索。
- 主模型均为确定性轻量方法，不用多随机种子制造重复证据。若敏感性抽样引入随机性，固定并记录种子 `20261109`。
- 默认关闭训练内 alpha 搜索和基础模型微调。不能因候选失败自动升级为大模型训练。
- 任一任务数据不满足最小条件：停止该任务学习模型训练，交付其覆盖与基线结果，其他任务继续。
- 时间／资源不足：优先完成 P0—P4 及主图表，明确列出未执行的 P5/P6 项目，不把待办写成实验结果。
- 发现新的单位、标签或时间定义问题：先暂停受影响任务；若需要改变冻结规则，新建 V3.1，不覆盖已经运行的 V3.0。

### 15.3 本轮完成定义

本轮实施完成需同时满足：

- Q01—Q12 均有处理状态和证据；未能消除的问题有明确适用边界。
- 所有符合数据条件的任务都完成预定主实验，所有不符合条件的任务都给出原因。
- 新候选与强基线使用同目标、同划分、同评分集合并报告覆盖。
- 固定半段、连续段、滚动、在线校准四类结果可清楚区分。
- 每个模块给出采用／回退／展示／证据不足的决定；不要求新模型全部胜出。
- 核心结果可复算，旧实验保持可追溯，图册可以打开且无误导性标签。
- 报告明确：当前仍是单人、设备测量尺度上的回顾性原型，尚无跨人泛化、独立临床验证或干预因果证据。
